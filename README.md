#  Amazon Sales Performance Analysis | Excel Dashboard

### Turning Raw Data into Meaningful Business Insights

## 📌 Project Overview

This project focuses on analyzing sales performance using Microsoft Excel. It features an interactive dashboard designed to explore sales trends, profitability, customer behavior, regional performance, and payment methods.

The project transforms raw sales data into meaningful business insights using Pivot Tables, Pivot Charts, KPI calculations, and interactive slicers.

##  Project Objectives

- Analyze overall sales and profit performance.
- Identify high-performing product categories.
- Understand regional and city-wise sales distribution.
- Analyze customer purchasing behavior.
- Evaluate different payment methods.
- Track monthly sales trends.
- Present key business metrics through an interactive dashboard.

##  Tools & Technologies

- Microsoft Excel
- Pivot Tables & Pivot Charts

- Data Cleaning & Transformation
- Data Analysis

##  Dashboard Features

- **Monthly Sales Analysis:** Tracks monthly sales trends and performance.
- **Category Performance:** Compares sales across different product categories.
- **Payment Analysis:** Examines the distribution of orders by payment method.
- **City Performance:** Identifies cities contributing to overall sales.
- **Regional Performance:** Analyzes profitability across different regions.
- **Customer Analysis:** Examines purchasing patterns across customer segments.

##  Project Structure

The Excel workbook contains five worksheets:

1. **Dashboard:** Interactive dashboard with KPI cards, charts, and slicers.
2. **Amazon_Data:** Structured sales dataset.
3. **Pivot_Table:** Pivot Tables used for detailed analysis.
4. **KPI:** Key performance indicators and calculations.
5. **Data_Dictionary:** Field descriptions, data types, and additional information.
